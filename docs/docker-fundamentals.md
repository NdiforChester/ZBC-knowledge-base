Docker Fundamentals
What is Docker?

Docker is a platform used to package applications and their dependencies into containers so they can run consistently across different environments.

A container includes:

Application code
Runtime
Libraries
Dependencies
Configuration files

This solves the common problem:

"It works on my machine but not on the server."

What is a Container?

A container is an isolated environment used to run an application.

Containers:

are lightweight
start quickly
share the host OS kernel
package everything needed to run the application

Example:

Frontend container
Backend container
Database container
