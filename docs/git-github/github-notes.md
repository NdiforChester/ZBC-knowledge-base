Notes on GitHub

🔹 Meaning of GitHub

GitHub is a cloud-based platform used to store, manage, share, and collaborate on software projects using Git version control.

GitHub allows developers and teams to:

host repositories online
collaborate on projects
track changes
review code
manage development workflows

GitHub works together with Git.

* Simple Definition

GitHub is like:

“An online storage and collaboration platform for code and software projects.”

It helps teams work together from anywhere in the world.

⚙️ Main Functions of GitHub

1️⃣ Repository Hosting

GitHub stores Git repositories online securely.

Repositories contain:

code
documents
project files
configuration files

2️⃣ Collaboration

Multiple developers can:

work together
share updates
contribute to projects

without overwriting each other’s work.

3️⃣ Version Control Integration

GitHub uses Git to:

track file changes
manage versions
restore older versions

4️⃣ Pull Requests

Developers can:

submit changes
request code reviews
discuss improvements

before merging into the main branch.

5️⃣ Branch Management

GitHub supports:

feature branches
development branches
testing branches

This allows safer development workflows.

6️⃣ Issue Tracking

Teams can create issues for:

bugs
tasks
feature requests
project tracking

7️⃣ Code Review

Developers can:

comment on code
suggest changes
approve updates

before merging.

8️⃣ Project Management

GitHub provides:

project boards
milestones
task management tools

9️⃣ Backup & Security

Repositories are stored in the cloud, reducing the risk of losing project files.

🖥️ How to Use GitHub
🔹 Step 1 — Create a GitHub Account

Visit:

GitHub Official Website

Sign up for an account.

 2 — Create a Repository

After logging in:

1 Click:

New Repository
2 Enter:
repository name
description
3 Choose:
Public
or
Private
4 Click:
Create Repository

 3 — Connect Local Git Repository

Example:

git remote add origin https://github.com/username/repository.git

 4 — Push Files to GitHub

git add .
git commit -m "First commit"
git push -u origin main

This uploads files to GitHub.

 5 — Clone a Repository

To copy a repository from GitHub:

git clone https://github.com/username/repository.git

 6 — Create Branches

git checkout -b feature-branch

 7 — Create Pull Requests

After pushing changes:

open GitHub
click:
Compare & Pull Request
request code review
merge changes

* Difference Between Git and GitHub

Git                      	GitHub

Version control system	        Cloud hosting platform
Installed locally on computer	Accessed online through web
Tracks file changes      	Stores repositories online
Works offline           	Requires internet for cloud access
Manages versions        	Manages collaboration
Created by Linus Torvalds	Owned by Microsoft
