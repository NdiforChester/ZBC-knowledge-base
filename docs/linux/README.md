# Linux Documentation

This directory contains Linux learning notes for new engineers. The goal is to build confidence with the operating system most commonly used in cloud, DevOps, container, and server environments.

## Scope

The Linux section covers:

- Linux architecture and distributions.
- Filesystem layout.
- Command line navigation.
- File and directory management.
- Users, groups, and permissions.
- Processes, services, and package management.
- Networking basics.
- Logs and troubleshooting.
- Bash scripting for automation.

## Recommended Reading Order

1. [Linux Fundamentals](linux-notes.md)
2. [Bash Scripting](bash-scripting.md)

## Expected Outcome

After completing this section, a learner should be able to use the Linux terminal, manage files and services, understand permissions, inspect logs, and write basic scripts for repeatable tasks.
