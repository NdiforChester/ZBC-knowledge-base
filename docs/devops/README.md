# DevOps Documentation

This directory contains collaboration, automation, container, orchestration, CI/CD, and troubleshooting notes. It connects the project workflow with the tools engineers use in real teams.

## Scope

The DevOps section covers:

- Git and GitHub collaboration.
- Pull requests, issues, reviews, and branch management.
- Docker containers.
- Docker Compose and image registries.
- Kubernetes basics.
- CI/CD documentation.
- Troubleshooting common Git and GitHub problems.

## Recommended Reading Order

1. [Git and GitHub Guide](git-github-guide.md)
2. [Docker Fundamentals](docker-fundamentals.md)
3. [Docker Compose and Registries](docker-compose-registry.md)
4. [Kubernetes Basics](kubernetes-basics.md)
5. [CI/CD Documentation](ci-cd-documentation.md)
6. [Troubleshooting Guide](troubleshooting-guide.md)

## Expected Outcome

After completing this section, a learner should understand how teams collaborate through GitHub, how containers package applications, how Kubernetes runs containers at scale, how CI/CD automates delivery, and how to recover from common workflow mistakes.
