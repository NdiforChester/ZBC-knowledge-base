# AWS Documentation

This directory introduces Amazon Web Services for students learning cloud engineering and DevOps. The goal is to explain AWS from first principles, then connect the concepts to real infrastructure decisions.

## Scope

The AWS section covers:

- Cloud computing fundamentals.
- AWS global infrastructure.
- Identity and access management.
- Compute services.
- Storage services.
- Database services.
- Monitoring, logging, and operational best practices.

## Recommended Reading Order

1. [AWS Core Concepts and Compute Services](aws-core-concepts.md)
2. [AWS Storage and Database Services](aws-storage-services.md)
3. [AWS Storage and Database Practice Guide](aws-storage-services-database.md)
4. [Building Scalable and Secure Web Applications on AWS](aws-scalable-secure-webapps.md)

## Expected Outcome

After completing this section, a learner should understand how AWS organizes cloud resources, how access is controlled, when to choose common compute and storage services, and which best practices reduce operational and security risk.
